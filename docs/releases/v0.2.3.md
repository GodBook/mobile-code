# Mobile Code 0.2.3

- 代码高亮采用参考图的配色：红色关键字、青色类型、紫色函数、粉色预处理指令、蓝色字符串和分层彩色括号。C、C++、Python、Java 均使用本地语法分析。
- 设置中明确提供“亮色”和“暗色”两种主题，覆盖编辑器、行号、折叠与调试标记、控制台、补全和诊断弹窗。切换主题保留代码及撤销历史。
- 合并连续输入产生的语义更新，串行发送全文消息，减少大文件编辑时的内存堆积。缩减高亮分析的临时内存，关闭文件与快照时释放编辑器资源。
- 控制台仅在有新输出时更新；减少无变化的界面重绘、设置写入与全文复制。修复快速关闭标签页时的指示条越界，以及启动恢复项目与新操作之间的竞争；恢复内存释放后的语义补全。
- 横屏或键盘弹出后优先保留可编辑区域。空间不足时收起辅助栏，控制台可在独立面板中展开，避免编辑区被挤到不可见。

Android 10+，仅 ARM64。保留原有签名，可覆盖安装并保留项目。C17、C++17、Python 3.13、Java 17 的运行、调试和语义补全继续在本地离线完成。

Android 15 ARM64 真机29项回归、6项单元测试及484个原生文件审计全部通过。可见1MiB源码打开约0.43秒，80次输入至下一帧回调P95约30.8毫秒；1MiB词法回退扫描80毫秒。具体方法、PSS采样和限制见 docs/VERIFICATION.md。

当前设备为4KiB页；16KiB真机、完整Android/厂商矩阵、物理输入完整时延及长期后台低内存行为仍待验证。
