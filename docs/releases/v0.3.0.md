# 0.3.0 · 手机编程体验升级

本次围绕保存恢复、项目文件管理、代码阅读和运行调试改进工作台。四种语言的编译、运行、调试与语义服务继续全部在本机离线完成。

- 保存状态按文件区分待保存、保存中、成功与失败。失败提示保留在工作台，可重试或直接导出内存中尚未保存的代码；恢复草稿需要用户对照确认后使用。
- 标准输入写入成功后才清空对应草稿，失败保留内容。运行、编译、暂停和输入结束时的可发送状态分开处理，支持显式结束输入。
- 首页提供项目名称搜索、置顶、最近打开和继续入口；配置损坏的项目仍显示恢复说明，可导出原目录。ZIP 导入可取消，混合语言项目可明确选择运行语言。
- 文件按目录展示，可搜索、移动、重命名及移入回收站。项目支持重命名、复制和回收恢复；简单文件移动不会自动改写代码引用或 Java 类名。
- 新增快速打开、行跳转、项目文本搜索和内嵌查找替换。文件内搜索支持大小写、整词、正则和结果计数；调试只读状态仍禁止替换。
- 恢复打开标签、各文件位置和项目观察表达式；提供关闭其他/已保存标签与重新打开关闭标签。增加专注编辑、跟随系统主题、控制台字号、语言相关符号栏和快捷键说明。
- 增加存储盘点、运行历史、日志及生成文件导出。清理需要明确确认，排除当前快照、源代码、恢复草稿和待安装更新；回收站不会自动永久清空。
- 问题列表区分实时分析和运行快照，可筛选来源、文件及严重度。控制台说明显示范围，提供暂停跟随、视图清空、查找和已保存日志导出，日志仍有10MiB上限。
- 运行参数以独立参数项编辑，支持空字符串、空格和中文；Python/Java 提供入口候选。
- 调试界面增加断点绑定说明、变量详情与复制；变量子树的返回结果校验会话、暂停序号和栈帧。新增真实定义跳转、引用和文档大纲，Python 由内置 Jedi 实现，C/C++ 与 Java 使用已有语言服务器。
- 更新界面增加仅 Wi-Fi 下载、上次成功检查、下载所需空间、系统暂停原因及有效样本下的速度估计。检查仍不会自动下载，安装仍由安卓确认并校验原签名。

继续支持 Android10+、ARM64，minSdk29、compile/targetSdk37，应用级 debuggable=false。安装现有更新通道时沿用原签名，不卸载或清空项目数据。

兼容性证据以随源码提供的验收记录为准。当前可测试设备为小米9SE、Android15、4KiB页；16KiB实际运行、完整Android10～17/厂商矩阵、物理IME到显示的完整P95及长期后台矩阵仍待验证。完整依赖管理、Android/GUI工程、云开发和任意调试求值未纳入本版。
